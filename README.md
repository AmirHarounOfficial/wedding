## الملفات (نسخة PHP — للرفع على aaPanel)

| الملف | ما هو |
|---|---|
| `invitation.html` | الدعوة نفسها — الرابط اللي يتبعت للضيوف |
| `admin.html` | صفحتك انت: مين هيحضر ومين كتب تهنئة |
| `api.php` | بيستقبل الردود ويخزنها |
| `data.php` | الردود المخزّنة — **اعمله باك أب** |
| `.htaccess` | حماية إضافية (Apache) |

مفيش Node ولا PM2 ولا بورت ولا reverse proxy. PHP بس.

> `server.js` و `package.json` من النسخة القديمة (Node) — **متترفعش على السيرفر**.
> ملفات `.js` بتتقدّم كنص عادي، و `server.js` جواه كلمة الدخول.

## الرفع

1. **غيّر كلمة الدخول** في `api.php` أول الملف:
   ```php
   const ADMIN_KEY = 'sawsan-amir';   // ← غيّرها
   ```
2. aaPanel → Website → Add site (PHP 7.4 أو أحدث)
3. Files → افتح `/www/wwwroot/الدومين` → ارفع الـ zip → Unzip
4. امسح أي `index.html` افتراضي عمله aaPanel
5. الصلاحيات (مهم عشان يقدر يكتب):
   ```
   chown -R www:www /www/wwwroot/الدومين
   ```
6. SSL → Let's Encrypt → Force HTTPS

**الروابط:**
- الدعوة → `https://الدومين/invitation.html`
- صفحتك → `https://الدومين/admin.html?key=كلمتك`

لو حابب الدعوة تفتح على `https://الدومين/` مباشرة، غيّر اسم
`invitation.html` لـ `index.html`.

### لو حاجة مش شغالة

افتح: `https://الدومين/api.php?action=check&key=كلمتك`

بيقول لك نسخة PHP، ولو `data.php` موجود وقابل للكتابة، وعدد الردود.
لو `store_writable` طلع `false` → مشكلة صلاحيات، رجّع لخطوة ٥.

## ♪ إضافة موسيقى خلفية

1. ارفع ملف الصوت جنب `invitation.html` — مثلاً `music.mp3`
2. عدّل `invitation.html` ودوّر على `CONFIG` في أول الـ `<script>`:

```js
audio: { src: 'music.mp3', volume: 0.45 },
```

الموسيقى بتشتغل أول ما الضيف يضغط على الظرف — المتصفحات بتمنع الصوت
قبل ما المستخدم يضغط، وده سبب وجود شاشة الظرف. وبيظهر زرار ♪ للكتم.

الصيغ: `.mp3` `.m4a` `.ogg` `.wav`

## باقي الإعدادات

كلها في بلوك `CONFIG` في `invitation.html`:

```js
start / end        وقت الفرح (بتوقيت مصر UTC+3)
venue / area       اسم القاعة والمنطقة  (سيبها '' عشان تختفي)
mapUrl             لينك جوجل مابس
dress              كود الملابس
whatsapp           رقمك بالكود الدولي أرقام بس — مثلاً '201001234567'
shareUrl           اللينك اللي الضيف بيشاركه (سيبه '' يستخدم لينك الصفحة)
```
