## الملفات

| الملف | ما هو |
|---|---|
| `invitation.html` | الدعوة نفسها — الرابط اللي يتبعت للضيوف |
| `admin.html` | صفحتك انت: مين هيحضر ومين كتب تهنئة |
| `server.js` | خادم صغير بيجمّع الردود (بدون أي مكتبات) |
| `data.json` | الردود المخزّنة — **اعمله باك أب** |

## التشغيل

```bash
node server.js
```

- الدعوة: <http://localhost:3000/>
- صفحتك: <http://localhost:3000/admin.html?key=sawsan-amir>

الضيوف على نفس الشبكة يفتحوها من `http://<الآي-بي-بتاعك>:3000/`.
عشان توصل لضيوف في أي مكان، ارفع الفولدر على أي استضافة Node
(Render / Railway / Glitch) — الكود Node عادي بدون dependencies.

> غيّر كلمة الدخول: `ADMIN_KEY=كلمتك node server.js`
> أو عدّل السطر `const ADMIN_KEY = ...` في `server.js`.

## ♪ إضافة موسيقى خلفية

1. حطّ ملف الصوت جنب `invitation.html` — مثلاً `music.mp3`
2. افتح `invitation.html` ودوّر على `CONFIG` في أول الـ `<script>`، وغيّر:

```js
audio: { src: 'music.mp3', volume: 0.45 },
```

خلاص. الموسيقى بتشتغل أول ما الضيف يضغط على الظرف — المتصفحات
بتمنع الصوت قبل ما المستخدم يضغط، وده بالظبط سبب وجود شاشة الظرف.
وبيظهر زرار ♪ تحت لكتم الصوت أو تشغيله.

الصيغ المدعومة: `.mp3` `.m4a` `.ogg` `.wav`

## باقي الإعدادات

كلها في نفس بلوك `CONFIG` في `invitation.html`:

```js
start / end        وقت الفرح (بتوقيت مصر UTC+3)
venue / area       اسم القاعة والمنطقة  (سيبها '' عشان تختفي)
mapUrl             لينك جوجل مابس
dress              كود الملابس
whatsapp           رقمك بالكود الدولي، أرقام بس — مثلاً '201001234567'
                   لو مليته، تأكيد الحضور بيفتح واتساب عندك كمان
shareUrl           اللينك اللي الضيف بيشاركه (سيبه '' يستخدم لينك الصفحة)
```

## اللي موجود في الدعوة

- ظرف بيتفتح بضغطة (وبيشغّل الموسيقى)
- الأسماء والتاريخ والمكان مع لينك الخريطة
- عدّاد تنازلي + إضافة للتقويم (Google / Apple)
- تأكيد الحضور مع عدد المرافقين
- سجل ضيوف — التهاني بتظهر لكل الضيوف
- مشاركة على واتساب
- تبديل عربي/English وتبديل نهاري/ليلي

## ملاحظة
